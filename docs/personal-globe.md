# Personal Globe / 个人地球仪

## 目标

在站点 header 的语言切换控件左侧增加一个低调的地球按钮。用户点击后进入全屏的个人地球仪，在不离开当前页面的情况下探索嘉昭曾经生活、学习、工作或旅行过的地点。

体验以个人故事为核心，不提供航班路线、自由缩放、GIS 图层或复杂游戏机制。

## 用户体验

### 入口

- 入口位于语言切换控件左侧，尺寸与主题切换按钮一致。
- 使用地球图标，hover 时以品牌橙色提示这是一个可探索入口。
- 点击后打开全屏 overlay，保留当前页面作为半透明背景。

### 探索状态

- 地球居中显示，用户可以鼠标或触控拖拽旋转。
- Atlas 复用全站缓慢漂移的动态彩色背景，并提高其饱和度与可见度，让地图页面比普通内容页更有沉浸感。
- 地球不持续自动旋转，减少视觉干扰与 GPU 占用。
- 到访地点显示为橙色兴趣点，兴趣点使用可聚焦的 HTML button，保证键盘访问与足够点击面积。
- 兴趣点在背面时隐藏；在正面时可交互。城市名称复用站点共享 Tooltip，只在 hover 或键盘聚焦时出现，并提升当前点位层级以覆盖附近的其他点。
- 页面底部是按内容文档顺序排列的全屏故事卡轨道，鼠标、触控板和触控均可左右拖动。轨道只渲染一份数据，在首尾停止，避免循环副本带来的内容重复感。
- 每张卡片使用更宽的横向结构：左侧为 `3:2` 圆角图片，右侧显示标题和第一人称详情；下方以分割线隔开三列信息，地点靠左、时间居中、可选详情链接靠右，三者使用相同的字号与中性色。点击卡片主体会让地球聚焦到对应地点，链接则直接进入详情页。
- 卡片轨道本身完全透明，让毛玻璃卡片直接悬浮在地球之上。原有年份、区间胶囊、时间点与当前年月均已移除；页面最底部只在选中记录后显示该条记录的地点与时间，并分别对齐内容区左右两端。

### 聚焦状态

- 点击兴趣点后，地球以缓动动画旋转至目标位置并放大。
- 桌面端与移动端都保持地球居中，底部故事卡轨道始终可见。
- 用户可以直接选择另一个兴趣点或底部卡片切换聚焦地点，也可以按 `Escape` 返回探索状态。
- `Escape` 先退出聚焦状态，再退出整个地球仪。

## 首版地点

首版只使用站点已有、可以核实的经历和文章，不新增推测性个人故事：

- 北京：BJMUN 与微软经历
- 洛杉矶：ArtCenter 学习经历
- 新加坡：INSEAD 学习与教学经历
- 上海：蚂蚁国际经历
- 广州：网易互娱经历
- 旧金山：2024 加州之行

地点与路线集中存放在 `content/personal-globe.md`。它是 Atlas 唯一且完整的数据源，不会从履历、文章或其他文件同步字段：

- 每条记录显式填写 `coordinates`、`location`、`time`、`title` 与 `content`；`location` 只写城市名，不附加国家或地区。
- `image`、`bubble`、`href`、`instagram` 可选；图片可以复用 `public/assets/` 中的现有素材，站内链接可使用 `{lang}` 语言占位符。
- `instagram` 保存公开帖子、Reel 或 Instagram TV 的完整 URL。填写后卡片显示一个新窗口打开的 `Instagram ↗` 链接；它不参与经历点分类，也不会引入 Instagram embed 脚本。
- 同一坐标下只要有一条记录填写了 `href`，该地点就归类为经历点，并使用较大的落地圆片与 pin；没有链接的生活和旅行记录使用较小尺寸。
- `time` 与 `location` 同时以 `400` 字重显示在每张卡片的分割线下方；对应故事卡被选中后，页面最底部信息栏会居中显示“地点 · 时间”。
- 气泡只在记录显式填写 `bubble` 时出现。
- 同一地点可以维护多条记录；这些记录必须使用完全相同的 `coordinates`。地球会将它们合并为一个兴趣点，底部轨道仍按文档顺序分别显示每张故事卡。
- `places` 的文档顺序只控制底部故事卡的前后顺序；曲线不再从相邻卡片自动推导。
- `routes` 以显式的 `from` / `to` 单独维护曲线和光点顺序。路线端点不必对应故事卡或兴趣点，因此芝加哥可以只作为路线节点存在。
- 中文与英文可以写在同一个字段下；若只写普通字符串，则两种语言共用。

## 技术方案

### 渲染底座

使用 COBE v2：

- WebGL 渲染；
- 零运行时依赖，包体较小；
- 原生支持 marker、明暗模式和视角更新；
- marker 可以绑定普通 DOM 元素；
- 地点默认与选中状态只显示落地圆片，pin 仅在 hover 时出现；pin 垂直于当地球面，投影长度会在正对观察者时缩短、靠近轮廓时伸展；落地点是根据球面透视动态压缩的无描边圆片，点击热区、标签与气泡都随点位可见度收缩；
- 只有 `routes` 中显式维护的点到点路线会用细空间弧线串联。当前依次为北京 → 洛杉矶 → 芝加哥 → 洛杉矶 → 新加坡 → 上海 → 北京。路径方向沿两点之间的球面最短路线插值，高度使用正弦曲线从地表立即抬升，并在中点达到统一弧顶，因此不同距离的路线具有近似相同的离地高度。弧顶高度由 `personal-globe-overlay.tsx` 的 `ARC_APEX_HEIGHT` 控制，当前为 16% 球半径。页面按 `routes` 顺序每 3 秒选择下一段弧线，发射一个黄色小光点并在 2.4 秒内沿曲线移动到终点；光点使用轻量 DOM 投影，拖动或聚焦地球时仍会贴合曲线。整段路径的半径始终不小于球半径，因此不会穿入球体；
- 底部导航以单份同序故事卡组成透明横向轨道，最底部的信息栏居中呈现“地点 · 时间”；
- 项目锁定 COBE 2.0.1，并通过 `scripts/patch-cobe.mjs` 为 arc 增加可选的逐条 `height`；补丁会在 `postinstall` 自动、幂等地应用；
- 支持销毁实例并释放 WebGL 上下文；
- MIT License。

### 性能约束

- COBE 使用客户端动态加载，只有进入独立 Atlas 路由后才初始化 WebGL。
- 不使用粒子系统、云层、地形、国家多边形或后处理；路线动画始终只有一个 `6px` DOM 光点。
- 地球不自动持续旋转。
- 动画仅用于进入、拖拽惯性、地点聚焦与单个路线光点；页面不可见或用户要求减少动态效果时隐藏光点。
- Canvas DPR 桌面端上限为 1.5，移动端为 1。
- `mapSamples` 根据屏幕尺寸保持在约 6,000–10,000。
- Atlas 目前只有少量卡片，进入页面后会预载全部卡片图片（总量约 `700KB`），避免快速横向滚动时出现懒加载空白；卡片同时固定在独立合成层以减少毛玻璃滚动闪烁。
- overlay 关闭时销毁 COBE 实例。
- 页面不可见时停止动画。

## 可访问性与降级

- 所有地点都是有名称的 button，支持 Tab 与 Enter/Space。
- overlay 使用 dialog 语义，打开时锁定背景滚动并将焦点移入。
- 支持 `Escape`，关闭后焦点返回入口按钮。
- 遵循 `prefers-reduced-motion`：取消进入和聚焦的连续动画，直接更新视角。
- WebGL 初始化失败时显示地点列表，故事内容仍然可访问。
- UI 同时提供中文和英文文案。

## 验收标准

- header 入口在桌面端与移动端均不拥挤。
- 地球可以通过鼠标和触控拖拽。
- 每个兴趣点都可以点击并正确聚焦。
- 桌面端与移动端都显示可左右拖动的底部故事卡轨道，且每条记录只出现一次。
- 中英文切换后地点与界面文案同步。
- 打开地球前不会初始化 WebGL。
- 关闭 overlay 后没有残留滚动锁、动画帧或 WebGL 上下文。
- TypeScript 类型检查和 Next.js production build 通过。
